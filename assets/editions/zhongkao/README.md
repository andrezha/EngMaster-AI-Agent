# 初中英语正式版数据包

本目录是可发布的初中版产品数据，不是研究样例。

- 产品词头：1609 条（覆盖课程边界证据中的 1651 个规范化词元）
- 免费体验词汇：30 条，与正式词表同步抽取
- 初中短语：250 条
- 初中不规则动词：90 条
- 主题场景：独立人工编排 712 个主题明确的词头；不强迫代词、介词及宽泛抽象词进入场景
- 未进入主题场景的词仍保留在完整词表，并可按适用条件进入词根、音形或同反义记忆

边界表仅作为课程范围证据；含义、音标和产品字段沿用本项目已有开放许可数据链，初中独有词条由项目独立整理。详见 manifest.json、validation_report.json 和第三方许可文件。
