# EngMaster 四级短语表独立编制规则

版本：1.0  
制定日期：2026-08-09  
适用范围：初中、高中、大学英语四级（CET-4）、大学英语六级（CET-6）短语数据集

## 一、编制目标

从零建立一套来源可追溯、阶段边界清楚、可以重复构建的英语短语母表，并从同一母表导出不同学习阶段的数据。

本项目不寻找或宣称存在一张全国统一的“官方必备短语表”。官方文件用于确定阶段词汇范围和语言能力要求；具体短语由本项目依据开放语言证据独立选择、分级、释义和编排。

## 二、与旧短语表彻底隔离

现有 `assets/short_phrase.json` 及其备份不得作为新短语表的任何输入，包括：

- 不读取其中的573个短语作为候选索引；
- 不继承短语选择、顺序、编号或分组；
- 不复制中文释义、英文例句或中文例句；
- 不用新表与旧表的重合率决定收录与否；
- 新构建脚本不得接受旧短语文件路径作为参数或依赖项。

旧文件只作为历史产品文件保留。未来替换产品数据时另行提交，不能在新表构建过程中覆盖旧文件。

## 三、官方范围依据及边界

### 3.1 初中阶段

依据：《义务教育英语课程标准（2022年版）》及其附录词汇表。

- 教育部通知：<https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html>
- 课标说明词汇包括单词、短语、习惯用语和固定搭配等形式。
- 三级要求围绕相关主题学习和使用约1600个单词，并学习一定数量的习惯用语或固定搭配。
- 课标没有逐条给出全国统一的初中短语清单。

因此，“初中”表示本项目依据义务教育阶段能力目标独立判断的适用层级，不表示该短语被教育部逐条列入官方清单。

### 3.2 高中阶段

当前边界依据：《普通高中英语课程标准日常修订版（2017年版2025年修订）》及其附录2词汇表；2020年修订版保留为历史版本证据。

- 2025公开存档副本：<https://dfl.aku.edu.cn/__local/7/7E/8F/0D793808E59C18DC89FA5F169D6_3803EAF5_3CB621.pdf>
- 本项目已分别存档2025版和2020版课标PDF、下载记录及SHA-256。
- 2025版附录说明声明3100词，其中义务教育1600词、一星500词、二星1000词；逐条核验印刷正文实际为3099条（1600/502/997）。项目保留印刷事实并公开记录差异，不猜测修补。
- 课标要求在语境中学习习惯搭配、积累词块，并学习一定数量的短语。
- 附录2明确说明：“本词汇表不列词组和短语。”

因此，不得把独立编制的高中短语表称为“教育部官方高考短语表”“高考固定范围”或“课标附录短语表”。

### 3.3 CET-4与CET-6阶段

依据：《全国大学英语四、六级考试大纲（2016年修订版）》中的四级能力说明和考试词表。

- 教育部教育考试院CET大纲页：<https://cet.neea.edu.cn/html1/folder/16113/1588-1.htm>
- 截至2026-08-09，该页面仍列出上述英语考试大纲。
- 大纲及词表用于限定四、六级词汇范围和能力要求；词表中六级词用 `★` 标出。
- 本项目未发现官网逐条发布的独立“CET-4/CET-6必备短语表”。

因此，“CET-4常用短语”和“CET-6常用短语”表示依据相应范围独立筛选的备考与学习材料，不表示考试机构逐条指定。

## 四、数据分层方式

新系统采用“一张母表、首次引入层级、累计导出”的结构。

| `introduced_level` | 含义 | 工作目标数量 |
|---|---|---:|
| `junior` | 初中阶段首次引入 | 约250条 |
| `senior_high` | 高中阶段首次引入 | 约200条 |
| `cet4` | CET-4阶段首次引入 | 约300条 |
| `cet6` | CET-6阶段首次引入 | 约300条 |

累计产品视图为：

- 初中常用短语：只含 `junior`，约250条；
- 高中常用短语：含 `junior + senior_high`，约450条；
- CET-4常用短语：含前三层，约750条；
- CET-6常用短语：含全部四层，约1050条；
- 同时允许导出“高中新增”和“四级新增”两个非累计视图。

上述数量是产品设计目标，不是官方规定。不得为凑整数收录低质量短语；最终数量如果调整，必须在构建清单中说明原因。

## 五、候选短语的独立来源

候选短语只能由以下路径产生：

1. 从相应阶段官方词汇范围中的高频动词、名词、形容词和介词出发，独立生成待核对搭配；
2. 从 Open English WordNet 等许可证已归档的开放词典中提取多词词条、短语动词和固定表达；
3. 从确认允许本项目用途并已存档许可证的开放语料中取得共现或频率证据；
4. AI可以提出待核对候选，但AI输出本身不作为语言事实来源；
5. 教材、商业词典、培训机构词表和网络转载表只能用于发现疑点，不能批量抽取或作为发布数据来源。

任何新增外部来源在使用前必须保存：名称、版本、下载地址、取得日期、许可证文本、文件哈希和实际用途。许可不明的来源不得进入构建链。

## 六、短语入选通用条件

每条短语必须同时满足：

1. **形式成立**：开放词典有词条证据，或合规语料能证明该组合稳定使用；
2. **意义稳定**：整体有可教学的固定意义、典型搭配功能或明确语法功能；
3. **学习价值**：适合听、说、读、写中的至少一项，不只是偶然出现的自由组合；
4. **层级合理**：组成词、抽象程度、语体和使用场景符合首次引入阶段；
5. **表达自然**：不是中式英语、残缺结构或只在极窄专业领域使用的组合；
6. **证据完整**：能记录形式来源、阶段判断理由、释义方法和QA状态；
7. **可独立表达**：中文释义和例句可以由本项目原创完成，不依赖复制第三方表述。

只满足“语法上可以组合”而不具有固定搭配价值的内容，不作为短语收录。

## 七、各阶段判定标准

### 7.1 `junior`

优先满足以下特征：

- 组成词原则上属于义务教育词汇范围；
- 用于家庭、学校、朋友、兴趣、饮食、健康、交通、节日和日常活动等基础主题；
- 结构较短、意义具体、口语和基础阅读中常见；
- 初中生能够在简单句中主动使用；
- 不依赖复杂语法、抽象论证或正式公文语体。

### 7.2 `senior_high`

优先满足以下特征：

- 核心实词原则上处于高中累计词汇范围；
- 常用于高中阅读、完形、听力、语法学习或一般写作；
- 涉及较抽象的因果、观点、变化、责任、社会、科技和文化主题；
- 包括有学习价值的短语动词、习惯搭配、词块和语篇连接表达；
- 不以大学专业阅读或高度正式公文为主要使用场景。

### 7.3 `cet4`

优先满足以下特征：

- 核心实词原则上处于CET-4考试词汇范围；
- 对大学学习、校园生活、社会议题、说明文、议论文、听力、翻译或写作有明显价值；
- 相比高中层更抽象、正式或具有学术通用性；
- 不属于CET-6、考研或专业英语才有明显价值的低频表达；
- 若高中阶段已经自然且常用，不得为了均衡数量重复标为CET-4首次引入。

### 7.4 `cet6`

- 至少一个核心实词原则上属于CET大纲星号六级范围，或整体抽象度和语体明显高于四级；
- 适合较复杂的学术通用阅读、社会议题、论证、正式写作或六级听力场景；
- 不收录只在专业学科、历史制度或极窄地域语境中有价值的表达；
- 若四级或更早阶段已经自然且常用，不得仅因六级材料中可能出现而上移层级。

阶段判定以“适合首次系统学习的最低阶段”为准，而不是短语能够出现的最高考试阶段。

## 八、排除、降级和隔离条件

出现下列情况之一，应排除或进入待审区：

- 仅来自一个许可不明的网络词表；
- 开放词典和合规语料均无法确认；
- 结构残缺，必须依赖未标出的宾语、数量、从句或特殊语境；
- 中文释义与英文形式的适用范围不一致；
- 只是普通自由组合，没有独立教学价值；
- 过时、地域性很强、冒犯性强或专业性过窄；
- 与已收短语只有无教学意义的机械词形差别；
- 同一意义已有更自然、更常用的标准表达；
- 需要复制商业词典解释才能准确说明；
- 阶段证据不足，无法解释为何属于初中、高中或CET-4。

待审记录不得混入正式发布表。

## 九、规范化与斜线规则

1. `phrase` 每条只保存一个规范短语，禁止用 `/` 合并答案。
2. 可接受变体保存在 `accepted_variants` 数组中，每个变体单独成项。
3. `/` 只允许出现在中文释义文本确有需要的位置；不得承担英文答案分隔功能。
4. 人或物的占位统一使用 `{someone}`、`{something}`，不混用 `sb`、`sth`。
5. 所有格占位统一使用 `{one's}`；具体实现前必须测试应用能否正确显示和判题。
6. 动名词和不定式框架统一写为 `{doing}`、`{to_do}`，展示层再转换为自然形式。
7. 大小写、撇号、连字符和空格先规范化，再执行去重。
8. 英式和美式变体不合并写在主短语内，而由变体字段和使用说明处理。
9. 规范形式相同但意义明显不同的多义短语原则上保留一条记录，在义项数组中分开；只有教学任务需要分别练习时才拆分。

## 十、母表字段

每条正式记录至少包含：

| 字段 | 说明 |
|---|---|
| `record_id` | 新系统稳定编号，不沿用旧表ID |
| `phrase` | 唯一规范英文短语 |
| `normalized_phrase` | 用于查重和判题的规范化形式 |
| `accepted_variants` | 可接受英文变体数组 |
| `introduced_level` | `junior`、`senior_high`、`cet4`或`cet6` |
| `included_in` | 可导出的累计产品层级数组 |
| `phrase_type` | 短语动词、固定搭配、习惯表达、语篇连接等 |
| `headword` | 主要词头 |
| `pattern` | 必要的宾语、动名词或不定式框架 |
| `senses_zh` | 分义项的原创中文释义 |
| `usage_note_zh` | 用法、语体、易错点或变体说明 |
| `example_en` | 本项目原创英文例句 |
| `example_zh` | 与英文例句对应的原创中文译文 |
| `form_evidence` | 短语形式及变体证据 |
| `level_evidence` | 阶段词汇覆盖、频率及使用场景证据 |
| `selection_reason` | 收录及分层理由 |
| `definition_method` | 中文释义形成方式 |
| `example_method` | 例句形成方式 |
| `qa_status` | 自动检查及后续审核状态 |
| `human_review_claimed` | 是否确有人工专家审核；默认 `false` |

来源证据必须能回指资源名称、版本和条目或统计结果，不能只写“来自网络”“AI判断”或“常见”。

## 十一、中文释义和例句规则

- 中文释义依据开放英文语义证据选择义项后独立表述；
- 不批量翻译或改写旧表、商业词典、教材和培训资料的中文释义；
- 一个短语只保留各阶段真正需要的主要义项，不追求词典式穷尽；
- 英文例句全部新写，长度和语法难度须符合首次引入阶段；
- 例句必须真实体现目标义项，不能只出现相同字符串；
- 中文译文必须与英文例句逐义对应；
- AI用于起草和检查，不作为来源，不得宣称人工专家校订；
- 所有例句执行重复检测、敏感内容检查和阶段词汇覆盖检查。

## 十二、构建及证据流程

1. 存档三个阶段的官方文件、下载记录和哈希；
2. 确认可商业使用的开放词典和语料，存档许可证；
3. 从官方词汇范围和开放资源独立生成候选池；
4. 规范化形式、拆分变体、合并真正重复项；
5. 为每条候选收集形式成立和常用程度证据；
6. 按最低适合阶段分为 `junior`、`senior_high`、`cet4`、`cet6` 或 `hold`；
7. 独立编写中文释义、英文例句和中文译文；
8. 执行结构、来源、层级、自然度、重复和答案识别检查；
9. 生成JSON、CSV、Excel、审计报告、构建清单和SHA-256；
10. 通过Git提交固定脚本、来源和结果，确保过程可复算。

阶段词汇边界由 `tools/extract_phrase_stage_vocab_boundaries.py` 重建。脚本只读取已批准的官方范围文件，并显式记录 `old_phrase_file_read: false`；历史573条短语表不是其输入。

每一级先冻结英文范围，再制作中文释义和例句，避免在内容编写过程中随意改变收词范围。

## 十三、发布验收标准

单级正式发布前必须满足：

- 记录数与构建清单一致；
- `record_id` 和 `normalized_phrase` 全部唯一；
- 英文主短语中不存在用 `/` 拼接的多个答案；
- 所有变体均为数组元素并有证据；
- 每条都有明确的首次引入层级和收录理由；
- 每条至少有一项可追溯的形式证据；
- 中文释义、英文例句和中文译文完整；
- 例句与目标义项一致且没有批量重复；
- 待审记录为零或已完全隔离；
- 自动QA错误为零；
- 没有审核人员时明确标记 `human_review_claimed: false`；
- 发布文件、来源文件和许可证文件均有哈希记录。

## 十四、产品命名和对外表述

推荐名称：

- 《初中英语常用短语250》
- 《高中英语常用短语450》
- 《大学英语四级常用短语750》
- 《大学英语六级常用短语1050》

如果最终数量变化，应同步修改名称，不为保持名称强行补足。

推荐说明：

> 本表依据相应课程标准或考试大纲的词汇范围与语言能力要求，结合已记录的开放语言资源独立筛选、分级、释义和编写。数量为本产品实际收录规模，本表不是教育部门或考试机构发布的固定短语清单。

禁止使用：

- “教育部官方短语表”；
- “高考官方固定短语”；
- “CET-4官方指定750条”；
- “CET-6官方指定1050条”；
- “覆盖全部考试必考短语”；
- 在没有统计证据时声称“历年真题最高频”。

## 十五、当前决策

1. 旧573条短语完全退出新表构建链。
2. 新表采用四级累计母表，而不是维护四套互相矛盾的数据。
3. 先建立四级统一候选池，再跨级去重并按最低适合学习阶段冻结英文范围。
4. 在开放来源许可证没有核实并归档之前，不开始正式候选生成。
