# 初中短语英文候选池

这是自动生成的审查队列，不是最终约250条初中短语表。

候选只来自已批准来源：2025课标初中1600词边界、OEWN 2025、Moby Words II和Tatoeba英语CC0子集。历史573条产品短语表未读取，中文释义和例句尚未制作。

- `candidate_pool.csv`：符合阶段词形边界的OEWN候选，以及“Moby命中且Tatoeba出现”的补充候选；
- `priority_review_600.csv`：按透明启发式分数排列的前600条有语料出现证据候选；
- `report.json`：数量、输入输出哈希和未读取旧表声明。

`tatoeba_cc0_sentence_count` 仅表示在当前CC0子集中出现，不是中考考频。`priority_score` 只用于安排审查顺序，不能自动决定收录。下一步仍须逐条排除自由组合、专名、冷僻义、残缺结构和不适合初中的表达。
