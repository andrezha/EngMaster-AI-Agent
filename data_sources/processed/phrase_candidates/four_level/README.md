# 初中—高中—CET-4—CET-6统一英文短语候选池

本目录是四级累计母表的自动候选和审查队列，不是最终发布表。

- `candidate_pool.csv`：所有通过词形边界和来源准入的候选；
- `priority_review_*.csv`：按组成词最低允许层级拆分的优先审查队列；
- `report.json`：输入、输出哈希和构建统计。

`minimum_lexical_level` 只表示组成词允许进入的最低层级。最终 `introduced_level` 可以因语义抽象度、语体和使用场景上调，但不能无证据下调。Tatoeba次数只是当前CC0子集中的出现性证据，不是考试频率。

`oewn_dictionary_review` 表示OEWN已将其作为多词词条收录、但当前小型Tatoeba CC0子集没有命中。它可以进入人工/AI辅助语义审查，不能因语料未命中自动判为低频，也不能未经审查直接发布。

目标是统一筛出约1050条：初中新增约250、高中新增约200、CET-4新增约300、CET-6新增约300。所有层级跨级去重，每条短语只保留一个首次引入层级。
